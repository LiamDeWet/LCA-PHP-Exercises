# LCA PHP Exercises

## Repository Description

This repository contains my PHP exercises completed for Course 2: Backend Web Development at Life Choices Academy. The exercises introduce PHP fundamentals, logic and functions, and PHP with MySQL by building progressively more advanced applications.

## Exercises Included

### Week 2 – Exercise 01: PHP Fundamentals

**Folder:** `week2_ex01_php_fundamentals`

Topics covered:

- PHP syntax
- Echo and print
- Variables and data types
- Variable scope
- Built-in functions
- Embedding PHP in HTML

### Week 2 – Exercise 02: PHP Logic and Functions

**Folder:** `week2_ex02_php_logic`

Topics covered:

- Operators
- Conditional statements
- Loops
- Functions
- Arrays
- Discount calculator
- Grade calculator
- Minimum and maximum value functions

### Week 2 – Exercise 03: PHP and MySQL CRUD

**Folder:** `week2_ex03_php_mysql`

A complete Employee Management System built using PHP and MySQL.

Features:

- Create employee records
- View all employees
- Update employee information
- Delete employee records
- Department search
- Server-side input validation
- Prepared statements for database security
- Navigation between pages
