# LCA PHP Exercises

## Description

This repository contains my PHP exercises completed as part of the Life Choices Academy Backend Web Development Course (Course 2). These exercises introduce the fundamentals of PHP programming, including syntax, variables, data types, functions, and variable scope.

## Exercises

### Week 2 - Exercise 01: PHP Fundamentals

This exercise demonstrates:

- PHP syntax
- echo and print statements
- Variables and data types
- PHP built-in functions
  - date()
  - rand()
  - intval()
  - gettype()
- Embedding PHP into HTML
- BMI calculator
- Global variables
- Local variables
- Static variables

## Files

- intro.php
- variables.php
- scope.php
- casting.php (Stretch goal file)

## Exercise 02 – PHP Logic and Functions

### Project Folder: week2_ex02_php_logic

This exercise demonstrates PHP programming logic and reusable code through:

Arithmetic, comparison, assignment, and logical operators
Conditional statements (if, elseif, else, and switch)
Loops (for, foreach, while, and do...while)
Functions with parameters and return values
Budget and interest calculators
Age category and voter eligibility checkers
Tiered discount calculator
Stretch goals including a grade calculator, an improved budget calculator using arrays, and a function to determine minimum and maximum values
