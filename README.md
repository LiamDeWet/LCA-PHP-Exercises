# LCA PHP Exercises

## Description

This repository contains my PHP exercises completed as part of the Life Choices Academy Backend Web Development Course (Course 2). These exercises introduce the fundamentals of PHP programming, including syntax, variables, data types, functions, and variable scope.

## Exercises

### Week 2 - Exercise 01: PHP Fundamentals

This exercise demonstrates:

- PHP syntax
- echo and print statements
- Variables and data types
- PHP built-in functions
  - date()
  - rand()
  - intval()
  - gettype()
- Embedding PHP into HTML
- BMI calculator
- Global variables
- Local variables
- Static variables
